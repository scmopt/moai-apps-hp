3-Day Protocol

3日間のプログラム

構造化 → 最適化 → 統合の3ステップで、業務課題を解決するプロトタイプを構築します。

🏗️
Day 1
Foundational Alignment & Structuralization

基盤の合意形成と構造化

ドメインエキスパートへのヒアリングで暗黙知を抽出し、「理想的な回答」を定義。データをPydanticモデルで型安全に構造化し、入出力のスキーマを確定します。

  • ビジネス課題の理想的な回答・エッジケース・評価指標の策定
  • Pydanticによる入力・出力データモデルの構築
  • バリデーションルールの自動化（型制約・ビジネスルール）
📋 Pydanticデータモデル
🎯 評価指標
⚙️
Day 2
Optimization Strategy & Engine Development

最適化戦略の策定とエンジン開発

問題を分類し最適なソルバーを選定。実データでスケーラビリティテストを実施し、制約条件の妥当性をドメインエキスパートと確認します。

  • 既存ソルバー（VRP, Job-Shop等）のマッピングまたはAMPLカスタムモデルの構築
  • 商用ソルバー / OSS / メタヒューリスティクスの最適な選定
  • 本番規模データでの求解時間測定とチューニング
🔧 最適化エンジン
📈 ベンチマーク結果
🖥️
Day 3
Agentic UI Generation & System Integration

UI自動生成とシステム統合

Coding Agentを活用してPydanticモデルからStreamlit UIを自動生成。最適化エンジンとの接合、結果可視化、Human-in-the-loopの調整機能を統合します。

  • Pydantic-to-UI マッピングによるCRUD画面の自動生成
  • 最適化実行ボタン・プログレスバー・リアルタイムログ表示
  • ガントチャート・地図・グラフによる結果可視化
  • Human-in-the-loop：最適解のマニュアル調整と再制約チェック

FAQ

よくあるご質問

問題の難易度や参加人数によって変動します。詳細はお問い合わせください。

ご希望の場所で開催可能です。お客様のオフィスへの訪問、日本各地にあるMOAI Labのオフィス、またはオンラインのいずれでも対応可能です。

お客様が選択できます。架空のデータを使用することも可能ですし、事前にチームと連携してお客様自身のデータを統合し、Bootcampで使用することも可能です。

ニーズや関心に合わせて調整します。主にAGI4OPT、Agentic IBP (Agent Skills)とそれに含まれる各種最適化ソルバーが頻繁に使用されます。使用するソフトウェアは、扱うユースケースに合わせて決定します。

技術者・非技術者を問わず、幅広いユーザーが対象です。業務担当者（ドメインエキスパート）は少なくとも1名参加してください。高度な技術知識やコーディングスキルは必要ありません。ビジネス部門やIT部門など、組織全体から5〜20名のステークホルダーの参加を推奨しています。

お客様の都合に合わせて調整可能です。可用性、関心、ユースケースに応じて、最短1日から最長5日まで柔軟に対応します。最適な期間についてご相談ください。
